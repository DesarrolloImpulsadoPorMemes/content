# Guía de Contribución 🚀

¡Gracias por querer sumar humor al repositorio! Sigue estos pasos para añadir tu meme:

## Pasos para contribuir

1. **Imagen**: Guarda tu imagen en `public/images/content/` con un nombre descriptivo (ej. `mi-gran-bug.png`).
2. **Post**: Crea un archivo `.mdx` en `src/content/posts/` con el mismo nombre.
3. **Contenido**: Copia y rellena la siguiente plantilla:

```markdown
---
title: "Tu Título Épico"
image: "/images/content/tu-imagen.png"
imageAlt: "Descripción técnica para accesibilidad"
copy: "Un resumen corto para redes con #hashtags"
date: YYYY-MM-DD
published: true
category: "Frontend | Backend | DevLife | IA"
---

Aquí puedes escribir una reflexión o explicación más larga del meme.
¡Sé creativo!
```

4. **Pull Request**: Sube tus cambios y abre un PR. ¡Lo revisaremos lo antes posible!
